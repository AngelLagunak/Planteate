# Seguridad

Si encuentras un fallo de seguridad en Planteate, no abras una incidencia
pública: usa **Security → Report a vulnerability** en este repositorio de
GitHub (aviso privado al mantenedor).

Este repositorio no contiene claves ni datos personales: cada instalación
guarda sus claves en las Propiedades del script de su propio Apps Script y
sus datos en su propia hoja de Google. El modelo de seguridad está descrito
en el `README.md`, sección "Seguridad".
